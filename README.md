# KontenKu AI

KontenKu AI adalah aplikasi berbasis web untuk membantu kreator konten.

## Tujuan Proyek

1. Mengolah dataset konten.
2. Melatih model Machine Learning sendiri.
3. Mengevaluasi hasil prediksi model.
4. Menggunakan Generative AI untuk membuat ide, hook, caption, dan naskah.
5. Membuat aplikasi web yang mudah digunakan.
